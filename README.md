**Python, Django, NVIDIA Nemotron-3-Embed-1B, PostgreSQL, pgvector, Celery, Redis, Amazon S3, PyMuPDF, python-docx, Scikit-learn**

### Key Features

- Extracts text from candidate resumes in **PDF and DOCX** formats.
- Generates **2,048-dimensional vector embeddings** using NVIDIA Nemotron-3-Embed-1B.

- Calculates semantic similarity between resumes and job requirements.
- Generates AI-based resume-job matching scores.
- Processes resume scoring asynchronously using **Celery and Redis**.
- Retrieves resumes from **Amazon S3** for processing.
- Supports automated resume shortlisting for career portal and LinkedIn applicants.
- Integrates AI-based scoring into the existing recruitment workflow without disrupting core ATS functionality.
